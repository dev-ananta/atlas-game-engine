# Atlas Game Engine - Project Summary

This repository contains the current Atlas Game Engine MLP foundation.

## Implemented Foundations

- Studio project creation/open/save workflow
- Asset import pipeline in Studio
- Manifest normalization/validation in build-tools
- Tier-aware asset bundling with gzip compression
- `.game` packaging with checksum and distribution encryption modes
- Runtime package loading with hardware detection and automatic quality tier selection
- CI workflows for studio/runtime/package/release validation
